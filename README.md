# Simulação Bancária com Python e SQLite3

Projeto de estudo desenvolvido para praticar **programação em Python** e os fundamentos de **bancos de dados relacionais** usando SQLite3.

A proposta foi representar informações de uma conta bancária em um banco de dados, exercitando a criação de tabelas e a inserção de registros. Desenvolvi o projeto de forma independente, sem utilizar ferramentas de inteligência artificial na programação, como parte do meu aprendizado em Análise e Desenvolvimento de Sistemas.

## Objetivo

Aplicar, em um exemplo prático, os conceitos iniciais de integração entre Python e um banco de dados, além de exercitar o uso de Git e GitHub para versionamento e publicação do projeto.

## Tecnologias utilizadas

- **Python 3:** linguagem utilizada para desenvolver o programa.
- **SQLite3:** banco de dados relacional usado para armazenar os dados do exercício.
- **Git:** controle de versão do projeto.
- **GitHub:** hospedagem e compartilhamento do repositório.

## O que foi praticado

- Criação e organização de tabelas no banco de dados.
- Inserção de valores e registros.
- Utilização de Python em conjunto com SQLite3.
- Versionamento do código e publicação no GitHub.

## Estrutura do projeto

```text
bancodedados/
├── main.py       # Código Python do exercício
```

## Como executar

**Pré-requisito:** ter o Python 3 instalado. O módulo `sqlite3` faz parte da biblioteca padrão do Python, portanto não exige instalação separada.

1. Clone este repositório:

   ```bash
   git clone https://github.com/Merlaine/bancodedados.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd bancodedados
   ```

3. Execute o arquivo Python:

   ```bash
   python3 main.py
   ```

> **Observação:** o repositório contém o arquivo `banco.db`. A execução do programa pode utilizar ou alterar os dados armazenados, conforme a implementação de `main.py`.
